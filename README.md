# Afif Jazimin — cybersecurity portfolio

A two-page static site at [l3t0x.github.io/portfolio](https://l3t0x.github.io/portfolio/).

- `index.html` — CTFs, projects, skills, and education
- `blog/index.html` — CTF recaps and writeups

The site uses plain HTML, CSS, and JavaScript. Its security laptop GIF is an original
asset in `assets/`. Push to `master` to deploy through the GitHub Pages
workflow in `.github/workflows/pages.yml`.
